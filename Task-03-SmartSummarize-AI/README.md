## 1. Executive Summary & Project Description

**SmartSummarize AI** is a production-ready, full-stack AI-driven web application designed to condense voluminous articles, technical documentation, academic papers, and lecture transcripts into clear, coherent, and actionable summaries.

Powered by Google's state-of-the-art **Gemini Large Language Model (LLM)** via the official unified `@google/genai` SDK, SmartSummarize AI delivers **real-time token streaming** directly to the user's browser via HTTP `ReadableStream` route handlers. Unlike generic chatbots, SmartSummarize AI features a purpose-built dual-panel productivity workspace with granular summary length controls, live word/character metrics, Markdown formatting, instant clipboard synchronization, and enterprise-grade prompt isolation.

---

## 2. Problem Statement

Information overload is one of the most pressing bottlenecks facing students, researchers, knowledge workers, and executives:
1. **Reading Inefficiency:** The exponential volume of research papers, market reports, and online documentation makes it nearly impossible to absorb every document in full.
2. **Loss of Critical Details:** Skimming or basic algorithmic extractors often omit critical nuances, figures, dates, and conclusions.
3. **High Latency & Poor UX:** Many traditional AI tools force users to wait 10 to 30 seconds with a blocking loading spinner before returning any text.
4. **Credential Security Risks:** Novice implementations often leak API keys in browser JavaScript bundles, leading to quota exhaustion and security vulnerabilities.

---

## 3. Project Objectives

- **Dedicated Summarization Pipeline:** Implement a focused workflow (Input &rarr; Length Tuning &rarr; Streaming Distillation &rarr; Output & Actions).
- **Official Google Gen AI SDK:** Utilize `@google/genai` with streaming responses enabled.
- **Real-Time Streaming:** Display words progressively as generated by the LLM, eliminating perceived latency.
- **Granular Summary Controls:** Provide 3 distinct summary modes (Short, Medium, Detailed) that demonstrably modify the LLM's structure and depth.
- **Enterprise-Grade Security:** Keep `GEMINI_API_KEY` isolated strictly server-side within Next.js Node.js runtime route handlers.
- **Rigorous Validation & Resilience:** Enforce character limits (20,000 max), reject empty/whitespace queries, and handle transient rate limits with backoff retry loops.

---

## 4. Key Features

- ⚡ **Real-Time Token Streaming:** Direct streaming from Google Gemini to the frontend utilizing standard HTTP chunked transfer and `ReadableStream`.
- 🎚️ **Multiple Summary Lengths:**
  - **Short (3–5 sentences):** Crisp high-level executive takeaway.
  - **Medium (1–2 paragraphs):** Balanced overview capturing key themes and arguments.
  - **Detailed (Structured markdown):** In-depth breakdown with executive overview, bulleted key findings, and implications.
- 📊 **Real-Time Metrics & Reduction Counter:** Live character counter (max 20,000), word count, and post-summarization reading time and compression percentage calculation (e.g. *87% shorter, saved ~3 mins*).
- 📋 **One-Click Clipboard Export:** Instant copy to clipboard with responsive feedback.
- 🔄 **Regenerate & Clear Controls:** Easily re-prompt or reset inputs with dedicated, keyboard-accessible action buttons.
- 💡 **Preloaded Example Selector:** Instant one-click loading of sample articles (AI & Quantum Computing, Renewable Energy, Modern Web Architecture) for rapid testing.
- 🌓 **Dark / Light Theme Toggle:** Clean persistent theme state switching between high-contrast dark navy and modern clean light mode.
- 📱 **Fully Responsive Layout:** Optimized dual-panel grid on desktop and stacked mobile cards for smartphones and tablets.

## 6. Application Architecture

```
[ User Browser / Client ]
           │
           │  1. Paste Text (Max 20,000 chars) + Select Length (Short/Med/Detailed)
           │  2. Submit POST /api/summarize { text, length }
           ▼
[ Next.js API Route Handler (Server-Side) ]
           │  3. Validates text non-empty, <= 20,000 chars, valid length enum
           │  4. Injects System Instruction (Strict Fact Preservation & Prompt Isolation)
           │  5. Accesses process.env.GEMINI_API_KEY (Completely Hidden from Client)
           ▼
[ Official Google Gen AI SDK (@google/genai) ]
           │  6. Calls ai.models.generateContentStream({ model, contents, config })
           │  7. Implements 3x Exponential Backoff for transient 503 / 429 spikes
           ▼
[ Google Gemini LLM API ]
           │  8. Generates tokens
           ▼
[ HTTP ReadableStream (Transfer-Encoding: chunked) ]
           │  9. Encodes chunks via TextEncoder and streams to client
           ▼
[ Client UI (OutputPanel.tsx) ]
              10. Progressively decodes and renders Markdown in real time!
```

## 8. Environment Configuration & Setup

### Step 1: Obtain a Google Gemini API Key
1. Navigate to [Google AI Studio](https://aistudio.google.com/apikey).
2. Sign in with your Google account.
3. Click **"Create API Key"** and select or create a project.
4. Copy the generated API key string (`AIzaSy...`).

### Step 2: Configure Local Environment
In the `smart-summarize-ai` directory, copy `.env.example` to `.env.local`:

```bash
cp .env.example .env.local
```

Open `.env.local` and add your key:

```env
# Google Gemini API Key (Server-Side Only)
GEMINI_API_KEY=your_gemini_api_key_here

# Supported Gemini Model (Default: gemini-3.1-flash-lite)
GEMINI_MODEL=gemini-3.1-flash-lite
```

> ⚠️ **Security Notice:** The `.env.local` file is explicitly listed in `.gitignore`. **Never** commit this file or expose your API key in version control.

## 9. Local Development & Installation

### 1. Prerequisites
- **Node.js:** v18.18+ or v20+ or v22+ (tested on Node v24.19)

```bash
cd smart-summarize-ai
```

```bash
npm run dev
```

Open your browser at [http://localhost:3000](http://localhost:3000) to view the live app.

```bash
npm run build
npm run start
```

A full end-to-end verification script is included to validate all API constraints, character limits, streaming responses, and summary lengths:

```bash

```

## 12. Deployment Instructions (Vercel)

This application is built strictly to Vercel and Next.js production specifications.

### Step 1: Push Project to GitHub
1. Create a new repository on [GitHub](https://github.com/new) named `smart-summarize-ai`.
2. Push your local code:
   ```bash
   git init
   git add .
   git commit -m "feat: complete production-ready SmartSummarize AI application"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/smart-summarize-ai.git
   git push -u origin main
   ```

### Step 2: Deploy to Vercel
1. Go to [Vercel Dashboard](https://vercel.com/) and click **"Add New Project"**.
2. Select your `smart-summarize-ai` GitHub repository.
3. In the **Environment Variables** section:
   - Key: `GEMINI_API_KEY` &rarr; Value: `your_gemini_api_key_here`
   - Key: `GEMINI_MODEL` &rarr; Value: `gemini-3.1-flash-lite`
4. Click **"Deploy"**.
5. Vercel will automatically build the Next.js application, enable streaming HTTP edge/serverless response headers, and deploy the live URL.
